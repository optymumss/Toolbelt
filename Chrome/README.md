# Toolbelt Downloads for Chrome

Hands Chrome's downloads to Toolbelt, adds “Download with Toolbelt” to the right-click menu,
and puts a Download button on videos that can be downloaded.

Set it up from Toolbelt: **Settings › Downloads › Set Up Chrome…** — Toolbelt copies this folder
to `~/Library/Application Support/Toolbelt/Chrome Extension` and tells you the three clicks
needed in Chrome (Developer mode → Load unpacked → choose that folder).
